## 每条记录包含

- **用户输入**: 测试用的用户消息
- **模型输出**: DeepSeek 生成的候选回复
- **人工判定**: pass(✅) / minor(⚠️) / major(❌) / test_issue(🔧)
- **评分**: 内容、人格、自然度 (1-5分)
- **问题**: 具体问题描述
- **建议**: 修改建议

## 判定标准

- **pass** ✅: 当前回复可直接保留
- **minor** ⚠️: 内容大体成立，但需要收紧
- **major** ❌: 存在事实/记忆/安全/边界/核心语义错误
- **test_issue** 🔧: 题目要求与产品能力冲突
