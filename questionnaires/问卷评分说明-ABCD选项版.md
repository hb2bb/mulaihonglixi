# 问卷评分说明（ABCD 选项版）

## 一、计分方法

每道题的四个选项对应不同的特质水平（1-9 级）。
选择哪个选项，就得到该选项对应的等级分数。

## 二、各维度得分计算

每个子维度包含若干道题，将该维度下所有题目的等级分数取平均值，得到该维度的最终等级。

例如：某人在「想象力」的2道题中分别选了 C（6级）和 D（9级），
则想象力维度的得分 = (6 + 9) / 2 = 7.5，四舍五入为 **8级（非常高）**。

## 四、置信度评估

以下情况建议降低该维度的置信度（confidence）：

- **题数少（2题）且两题答案差距大** -> confidence <= 0.6
- **自评与他评存在明显差异** -> 在 conflicts 字段中记录
- **情境验证结果与问卷结果不符** -> 以情境测试为准

## 六、使用建议

1. **自评 + 他评**：建议同时让 1-2 名熟悉该角色的人填写，比较差异
2. **情境验证**：问卷分数是起点，最终需要通过情境测试（参见模板 16节）验证
3. **避免裸分数**：将等级结果转换为自然语言描述后填入模板，不要直接写数字
4. **记录不确定性**：如果某维度的自评和他评差异较大，在 conflicts 字段中注明
